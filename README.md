# 🎯 Quest Completer Hotkey for BetterDiscord

Плагин для BetterDiscord, который позволяет запускать популярный скрипт для автоматического выполнения квестов Discord по нажатию горячей клавиши.

> ⚠️ **ВАЖНОЕ УТОЧНЕНИЕ:** 
> **Я НЕ ЯВЛЯЮСЬ АВТОРОМ САМОГО СКРИПТА ДЛЯ КВЕСТОВ.** 
> Этот плагин — лишь удобная обертка (обвязка), которая автоматизирует процесс. Оригинальный скрипт написан пользователем **nyxxbit**. 
> Вы можете найти его здесь: **[discord-quest-completer](https://github.com/nyxxbit/discord-quest-completer)**

---

## ⚠️ ВНИМАНИЕ: Риск для аккаунта!
Автоматизация действий и выполнение квестов через сторонние скрипты **нарушает Политику платформы Discord** (Self-Botting / Platform Manipulation). Использование данного плагина может привести к **блокировке вашего аккаунта**. Вы используете его исключительно на свой страх и риск.

---

## ⚙️ Как это работает

1. В обычной ситуации вам пришлось бы открыть консоль разработчика (`Ctrl+Shift+I`), скопировать код скрипта с GitHub и вставить его туда.
2. Этот плагин делает всё за вас. При нажатии горячей клавиши он автоматически скачивает **самую свежую версию** скрипта прямо с GitHub (raw-ссылка) и выполняет его внутри клиента Discord.

## 🚀 Установка и использование

1. Переместите файл `QuestCompleterHotkey.plugin.js` в папку плагинов BetterDiscord:
   * **Windows:** `%appdata%\BetterDiscord\plugins`
2. Перезагрузите Discord (`Ctrl+R`) и включите плагин в настройках (BetterDiscord -> Plugins).
3. Нажмите комбинацию клавиш **`Ctrl + Shift + Q`** (работает в любой раскладке).
4. Плагин скачает актуальный код квестов и запустит его. Вы увидите всплывающее уведомление о начале работы.
